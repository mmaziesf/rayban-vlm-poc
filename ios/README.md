# iOS companion (M7, optional)

> **Start with the [root README](../README.md#ios)** for build, Simulator, real-iPhone and CI instructions. This file is a short component map.

| Path | What | Status |
|---|---|---|
| `GlanceCore/` | Pure-Swift port of `phone/core` (intents, ring buffer, frame source, controller, meal parsing) | ✅ 11/11 XCTests on Linux (bot box, Swift 6.4) and on macOS CI |
| `GlanceApp/` | SwiftUI app + DAT 1.0.1 adapters (`Sources/DAT`) + Debug `MockRig` / `FakeRig` + XCUITests; Xcode project generated by XcodeGen from `project.yml` | ✅ builds for the Simulator on GitHub Actions; ✅ `MockLoopUITests` 4/4 (DAT MockDeviceKit link, gate) and ✅ `FakeGlassesUITests` 4/4 on Xcode 16.4 and 26.6 |
| `../.github/workflows/ios.yml` | macOS CI | gate = GlanceCore + build + fake-glasses UI tests |

Quick commands:

    ios/GlanceCore/run-tests.sh                               # Linux or macOS
    cd ios/GlanceApp && xcodegen && open GlanceApp.xcodeproj  # macOS; ad-hoc signing for the Simulator is preset

Mock assets in `GlanceApp/Resources/` are copies of the Android debug assets (H.265 hvc1 504x896 clip + meal JPEG).
Options, CI history (incl. the solved mock-link blocker) and the DAT Android↔iOS API map are in `../docs/IOS_OPTIONS.md`.
